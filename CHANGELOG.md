# Changelog

What's new in each release of Over9k, newest first. Over9k help & options shows
the entries of the releases you don't have yet, next to its Update button, so
each one is a single line that reads on its own.

## 0.1.0

- Releases: Over9k has versions now, and updates go release to release
- Search: Cmd+K (Ctrl+Shift+K off macOS) finds a project or an agent by name
- Sidebar: a line between computers, and their names in bold
- Parked: order by name or by last worked on (A–Z / Recent on its header)
- Usage: subscriptions that only a connected computer has get a row too
- Options › Look: Translucent, the sidebar and bars as frosted glass
- Options › Logo: your company's logo in the sidebar's header
- Options › Agent rows: ask before closing an idle agent (#13)
- Fix: a Claude subscription no longer shows as "API" with a cost (#12)
